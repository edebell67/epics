Agentic access has a hard boundary.

The Arena access offer is for research queries and observed audit activity only. A subscriber agent cannot execute trades, access a brokerage, manage customer funds, or act on someone else’s account.

What does the agent skill preview do?

It shows how a subscriber’s agent should authenticate, make permitted read-only API requests, preserve receipts, disclose live/historical/simulation mode and communicate limitations. It contains no token and cannot grant access by itself.

Is the Directory currently public?

No. The public page is an access and invoice route. The hosted runtime is activated for confirmed paid subscriptions after an operating-capacity check.

Can I use the results as trading advice?

No. The service is limited to historical research and auditability. It does not tell anyone what to buy, sell, hold or expect in the future.

Why request an invoice rather than instant checkout?

This keeps the pilot at zero new software cost while access capacity is controlled. A payment-link checkout can be added later once a no-fixed-cost payment account is selected.
