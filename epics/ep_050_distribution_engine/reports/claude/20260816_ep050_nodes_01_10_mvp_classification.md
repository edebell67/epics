No real customer or production identifiers are registered.

## Classification Legend

- **A — Required for First Live Loop:** cannot acquire and learn from a lead without the capability.
- **B — Manual Initially:** conceptually needed, but safely human-operated for the first loop.
- **C — Automate Next:** valuable automation after the loop is proven.
- **D — Scale Capability:** needed as services, geographies, clients, or volume increase.
- **E — Advanced Intelligence:** requires accumulated outcome data and optimization maturity.

## Candidate Combined MVP Contribution

The Claude-owned contribution to a smallest complete learning loop is:

1. **One registered target:** Node 01, using the confirmed synthetic `boiler_repair` / Blackheath, London target only.
2. **Minimal human-authored context:** Nodes 02–04 — problem/solution description, one audience segment, and the pinned conversion funnel — all manually authored fixtures, no generative automation.
3. **One real demand signal, manually curated:** Node 05 (optionally folding in Node 06), entered by a human from previously-observed search/question activity — no live query or scrape is executed by this allocation.
4. Nodes 07–10 are explicitly **not** required to prove the first loop and are deferred (C/D) — they add breadth, competitive context, and trend intelligence that matter at scale, not at first-loop proof.

This candidate subset feeds Node 11 (Intent Classification, Gemini-owned) with one opportunity derived from one manually-curated raw signal against one registered target. It does **not** authorize any live discovery, scraping, or automated collection: the master-spec wording "discover demand" remains manually substituted in this MVP candidate, consistent with the no-live-collection boundary confirmed for this allocation.

- **MVP approval:** Codex/orchestrator must approve the combined cross-owner subset (Claude Nodes 01–10 candidate above, plus Gemini's and Hermes's equivalents) before any `implementation/node_NN/` work begins.
- **Canonical contracts:** Any cross-owner schema (e.g. the raw-signal → opportunity shape Node 10 hands to Node 11) belongs first in `integration/proposals/claude/`, followed by producer/consumer review and orchestrator approval before promotion.
- **Safety:** No adapter may perform a live external action (search query, scrape, API call, publish) by default. All Node 05–09 fixtures are manually sourced and dated; Node 09 carries an explicit non-spam/no-auto-post guardrail into any future implementation.
