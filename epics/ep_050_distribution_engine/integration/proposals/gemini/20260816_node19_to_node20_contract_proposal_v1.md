## 3. Node 20 Consumer Validation Rules

1. **Compliance Gate:** Hermes Node 20 must reject any asset payload where `compliance_stamp.approved != true`.
2. **Deterministic Routing:** Uses `target_channels` and `cta_definition.destination_url` to construct the mock publishing plan.
3. **No External Execution:** Placement plan is authored as a mock record with `external_action=false`.
