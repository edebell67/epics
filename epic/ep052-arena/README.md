# EP052 Agentic Arena snapshot

Open `index.html` for the self-contained public Arena showcase and `owner.html` for the linked sample owner workspace.

Both pages embed their own CSS, JavaScript and limited illustrative data. They have no runtime dependencies or API calls, so they can be hosted as static files (including GitHub Pages). The owner workspace is a public demo using fictional sample records; it does not embed credentials or connect to the live owner account. The waitlist actions point to `https://thetechprinciple.com/waitlist/`.
