Build record

Every build
leaves a map.

Before anything non-trivial is built it gets a process map: a hierarchy of nodes, each with its own completion test. As it is built, an implementation checklist records the evidence. These are those documents, as they were used, not redrawn for presentation. Where a node is unfinished or unproven, the map says so.
