Architecture decisionThe Arena kernel knows nothing about strategies, portfolios, prices, funds, intelligence, orders, trades or returns. Domain adapters own those concepts and translate domain conditions into generic, durable Arena events.

Binding delivery rules

Kernel has no domain vocabulary

Generic core records subjects, capabilities, events, policies and actions; a domain adapter defines every business object and rule.

Identity is not a model or domain

An agent ID and owner ID remain stable when its model runtime or active domain changes.

Subscriptions stay in their harness

Subscription authentication is used only by its supported client—not copied into Arena.

Meaningful events wake models

Heartbeats, transport polling and display use ordinary code. Domain adapters decide when changed evidence becomes a meaningful event.

Policy is layered

The kernel enforces generic permissions and idempotency; each domain enforces its own limits, confirmations and mandatory actions.

Recover the same agent

Restart and reconnect replay unprocessed generic events using the existing identity, runtime assignment, cursor and decision state.
