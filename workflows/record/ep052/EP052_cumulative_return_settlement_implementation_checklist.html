Cumulative-return settlement checklist

  1. Selected strategy receives 1,000 configurable units and a versioned return reference.
  2. BUY stores entry cumulative return and charges the entry fee only.
  3. SELL uses FIFO lots and the agreed movement formula.
  4. Spread equals configured rate × absolute gross P&L.
  5. Exit fee is charged once per settlement.
  6. Positions expose gross and net mark-to-market.
  7. USD 250 configurable threshold warns and blocks new positions.
  8. Projected zero equity automatically exits and records positions.
  9. MCP exposes the market reference and compatibility alias.
