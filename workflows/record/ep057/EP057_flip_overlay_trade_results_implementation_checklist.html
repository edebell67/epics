Flip Result implementation checklist

  1. Preserve actual signal, entry index, and exit index.
  2. Resolve the opposite curve for the same model: BUY ↔ SELL.
  3. Store opposite entry value, exit value, and flip result on every side-aware trade.
  4. Render Flip Result per row and closed/open aggregate totals.
  5. Show unavailable state for side-less Total Net rotations.
  6. Run JavaScript syntax, calculation, and live browser checks.

No flip calculation may alter the actual overlay selection or P&L.
