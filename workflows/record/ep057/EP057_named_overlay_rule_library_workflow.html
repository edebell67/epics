Named overlay rules, saved once and assigned per portfolio

The operator creates a reusable rule from the overlay selection controls, names it, and saves it. Any named portfolio can then select that rule. The portfolio’s assignment persists independently; the replay overlay uses only the rule attached to the active portfolio.
