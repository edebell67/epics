Tracking data must be captured at the lowest level. Every visitor interaction — page load, button click, chat open, form focus, service view, scroll milestone, exit intent, booking click — generates an event. This ensures that when the owner asks "how did this promotion affect user behaviour?", the data exists to answer it without a new instrumentation cycle.
Day-over-day overlay is the primary comparison method. Current day data is displayed alongside the daily average for the previous X days (default 7) for every metric. This lets the owner see at a glance whether today's behaviour is in line with the weekly average, above it, or below it — without manually comparing numbers.
