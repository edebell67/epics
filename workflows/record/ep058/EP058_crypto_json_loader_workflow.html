Crypto quote ingestion

Existing Windows Python runner; one ordered tick.

Read the mapped forex file, parse forex and synthetic quotes, refresh fx_quotes.
Read the mapped crypto file and pass its complete JSON text to sp_000_import_crypto_prices, which refreshes crypto_quotes.
Both quote-table updates share the tick transaction. Any failure rolls the tick back and is logged.
Invoke the existing PostgreSQL trade-loop entry point only after both price sources load.
Success records separate forex and crypto counts/timestamps; failure records exception type without credentials.
