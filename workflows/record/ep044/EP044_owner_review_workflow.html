Key Rules from the Skill

  • No backend, no database, no API calls. The review UI is entirely static — same as every EP044 template.
  • Submission recipient is the operator's inbox (e.g. edward.bell@thetechprinciple.com), never the business owner's email.
  • No live tracking beacon. page_open_date_time is client-side only and travels with submission. Operator learns nothing until the owner submits.
  • Option 1 is pre-selected as "keep as-is" — the owner actively chooses to change something.
  • "No action required" omits numbered answers to distinguish genuinely-reviewed pages from unopened ones.
  • Owner never sees numbers — only the real option text. Numbers are in the email body for parsing.
  • Activation is a separate concern — payment/activation is not part of this review workflow.
  • Category skills tailor question/option wording to what matters for that trade.

Integration with EP047

  • Entry point: generated site with owner-preview.html and the review JS files
  • Review embed follows same pattern as assistant-embed.js (flag-toggled)
  • Reminder nudges are triggered by absence of any submission within an expected window
  • Future EP047 integration may also land submissions in a queryable store — not part of this skill
