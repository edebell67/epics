Daily local-news ingestion workflow

EP047 agreed operating model — a local Hermes or Codex agent creates an intake batch, then deployment automatically triggers a Render-hosted importer. The importer uses a durable ledger to import each batch exactly once, route every item to draft/review-required, and schedule bounded retries. No manual command, button, local database write, or client action is part of this workflow.

Safeguards — apply to both routes

Automatic retry

Ledger-backed bounded retry

Render automatically retries only transiently failed pending batches with bounded backoff; failed intake remains private and never publishes partial output.

→
Idempotency

Exactly-once batch import

Batch IDs and content hashes in a durable importer ledger prevent re-import after deploy retries, restarts, or scheduled reconciliation.

→
Audit

JSON never becomes public

Private JSON is deleted or retained under access control after import; the site exposes only approved DB records.
